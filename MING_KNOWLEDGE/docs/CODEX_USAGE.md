# Uso eficiente con Codex

Prompt recomendado:

> Antes de trabajar, lee `MING_KNOWLEDGE/index.json`.
> Consulta solamente la lección y los archivos de datos necesarios.
> No abras los PDF originales salvo que falte información o exista una discrepancia.
> No inventes contenido curricular.
> Al terminar, indica qué registros de MING_KNOWLEDGE utilizaste.

Ejemplos:

- Para un bug visual: normalmente no necesita leer MING_KNOWLEDGE.
- Para Reto Mixto L1-L3: consultar `progression.json`, `vocabulary.json`,
  `grammar.json`, `exercises.json` y `exam-patterns.json`.
- Para Hanzi: consultar `hanzi.json`; abrir la hoja PDF solo si faltan trazos/radical.
- Para China Adventure: consultar vocabulario, diálogos y progresión; no todo el libro.

Esto reduce contexto repetido y evita que el agente vuelva a interpretar cientos de páginas.
