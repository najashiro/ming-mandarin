# Fuentes originales

Este paquete no duplica los PDF originales para evitar un repositorio innecesariamente pesado.

`sources.json` contiene:
- nombre exacto;
- número de páginas;
- tamaño;
- SHA-256;
- lecciones relacionadas.

En el repositorio de Míng, mantén los originales en una carpeta estable, por ejemplo:

`Base de Datos/` o `MING_KNOWLEDGE/originals/`

y no cambies nombres sin actualizar `sources.json`.
