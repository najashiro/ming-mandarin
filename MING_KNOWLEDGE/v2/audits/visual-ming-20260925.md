## Límites

- Clasificación editorial preparada y comprobada por el modelo; no es una evaluación con alumnos ni una revisión humana independiente.
- No se generan imágenes, prompts, audio, tamaños, proporciones, estilos, rutas de recursos ni cambios de interfaz.
- Se clasifica el sentido del vocabulario registrado. Las notas documentan homógrafos, sinónimos, nombres y riesgos; no sustituyen las glosas ni el currículo originales.
- image_support no equivale a imagen propia: visual_grammar necesita apoyo estructurado y phrase_context apoya una frase, no una pista aislada.
- Los valores true de image_quiz_eligible son candidatos sujetos a validar cada imagen futura; no autorizan automáticamente el uso evaluativo de un recurso.
- Los sinónimos visualmente indistinguibles requieren respuestas alternativas o práctica contextual. Una imagen no puede exigir por sí sola una grafía única entre variantes equivalentes.
- La apariencia de una persona no demuestra nombre, nacionalidad, parentesco o profesión. Las identidades personales no se reconstruyen mediante retratos inventados.
- No se elimina vocabulario por carecer de imagen propia ni se cambian las lecciones exclusivas, ejemplos globales, pinyin o traducciones.
- Interno describe uso editorial, no privacidad del repositorio. La web recibe solo cuatro campos de clasificación y no las notas ni el método.
