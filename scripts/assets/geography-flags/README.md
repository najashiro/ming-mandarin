# Vectores de banderas para las lecciones 1–3

Los trece archivos SVG se copiaron sin modificar de [hampusborgos/country-flags](https://github.com/hampusborgos/country-flags), revisión `c09927e63705529bbf59ca6684cd9b23225dddad`, carpeta `svg/`.

El README del proveedor declara que sus diseños de banderas son de dominio público y explica que proceden de Wikimedia Commons con correcciones para acercarlos a sus especificaciones nacionales. Se conserva aquí esa procedencia; no se atribuye a Míng la autoría de las banderas. Las composiciones educativas, sus etiquetas y diagramas son originales de Míng.

`scripts/prepare-lessons123-geography.mjs` conserva el viewBox, la geometría y la relación de aspecto de cada vector original. Las fuentes oficiales consultadas, las URL de descarga fijadas a la revisión y el SHA-256 de cada archivo figuran en `docs/lessons123-geography-sources.json`. La relación de aspecto registrada describe el vector utilizado, sin afirmar que sea la única proporción admitida para cualquier uso ceremonial o institucional.

Los SVG compuestos se sirven localmente. No dependen de un CDN de banderas ni incluyen scripts, imágenes enlazadas o peticiones externas. Las etiquetas Hanzi/pinyin se toman del corpus activo y las imágenes se excluyen de las preguntas de reconocimiento visual porque muestran la respuesta.
