# Audio estático de la Lección 1

Los MP3 de este directorio se generan previamente con una voz neural de mandarín estándar de China continental. La aplicación los sirve como recursos estáticos y no necesita una voz china instalada en el dispositivo.

La correspondencia entre texto, pinyin y archivo se mantiene en `data/mandarin-audio.json`. El script `scripts/generate-pronunciation-audio.mjs` permite regenerarlos con la API de audio configurada solo en desarrollo.
